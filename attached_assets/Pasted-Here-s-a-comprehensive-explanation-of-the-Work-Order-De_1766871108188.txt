Here's a comprehensive explanation of the Work Order Detail Page for the MeterFlo Mobile team:

Work Order Detail Page - Complete UI/UX Design
Page Layout Overview
The page uses a vertical layout with:

Read-Only Banner (conditional) - Shows when user can't edit
Back Navigation - Link to return to work orders list
Summary Header Card - Key info at a glance
Collapsible Accordion Sections - Grouped form fields
1. Summary Header Card (Always Visible)
A prominent card with left border accent showing:

Left Side:

Title: customer_wo_id or fallback WO #[id]
Status Badge: Color-coded (Open=outline, Scheduled=blue, In Progress=yellow, Completed=green, Cancelled=red)
Service Type Badge: Primary colored
Quick Info Row (icons + text):

Customer Name (User icon)
Address + City (MapPin icon)
Scheduled Date/Time (Calendar icon)
Assigned User Name (User icon)
Right Side - Action Buttons:

"Start Meter Changeout" button (if applicable)
"Attachments (X)" button linking to files page
