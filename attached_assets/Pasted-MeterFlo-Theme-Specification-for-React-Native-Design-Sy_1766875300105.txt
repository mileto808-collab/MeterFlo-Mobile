MeterFlo Theme Specification for React Native
Design System Overview
Style: Modern Enterprise Dashboard (inspired by Linear, Notion, Carbon)
Typography: Inter (primary), JetBrains Mono (monospace for IDs/data)
Border Radius: 8px (0.5rem) - use consistently
Focus on: Data readability, quick task completion, minimal cognitive load

Component Styling Guidelines
Buttons:

Height: 36px (default), 32px (small), 40px (large), 36x36px (icon)
Border radius: 6px
Primary: primary background, primaryForeground text
Secondary: secondary background, secondaryForeground text
Ghost: transparent background, foreground text
Destructive: destructive background, destructiveForeground text
Hover: Apply elevate1 overlay
Pressed: Apply elevate2 overlay
Cards:

Background: card
Border: 1px solid cardBorder
Border radius: 8px
Padding: 16px (or 24px for larger cards)
Inputs:

Height: 40px
Border: 1px solid input
Border radius: 6px
Background: background
Focus: 2px ring with ring color
Badges/Pills:

Padding: 4px horizontal, 2px vertical
Border radius: 9999px (full pill shape) or 6px
Font size: 12px
Dark Mode Detection
Sync with system preference or provide a toggle. The web app uses a class-based toggle (dark class on root element).
